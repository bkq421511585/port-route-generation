# 邮轮航线后台管理系统 🚢

航线港口配置 + 行程代码解析 + 航线图生成（交互预览 / PNG 导出下载）。

## 功能

### 1. 港口配置（`/#ports`）
- 港口 CRUD：名称、英文名、类型（**母港 / 访问港**）、国家/地区、**经纬度**、别名、备注
- 新增/编辑时内置**地图点选坐标**：在高德底图上点击即可自动填入经纬度
- 关键词/类型筛选，双击行快速编辑
- **恢复默认数据**：一键还原内置 50 个真实港口（16 个母港优先，覆盖中日韩/东南亚/台海/远洋航线），首次启动自动写入

### 2. 航线图（`/#route`）
- 输入行程代码自动解析，例如：
  - `上海-福冈-长崎-济州-上海` → 5 天环线（Day1 上海登船 … Day5 上海下船）
  - `上海-海上巡游-上海` → 3 天（Day2 全天海上巡游，绘制小幅出海往返的两条柔和弧线，不画大圈）
- 所有港口间连线均为**轻微弧线**（约弦长 6% 的柔和小弧形，类似椭圆边），避免直来直去
- 海上巡游出海的朝向与距离**自动避开陆地**：内置 Natural Earth 50m 陆海位图（0.125° 精度），扫描 360° 选择往返弧线水域占比最高的方案
- 兼容：全角连字符 `－`、别名匹配（如 `冲绳那霸`↔`那霸`、`博多`↔`福冈`）、中途海上巡游（`A-海上巡游-B`）
- 支持 URL 直达行程：`http://localhost:5175/?code=上海-海上巡游-上海#route`
- 解析结果以时间线展示每日节点，未配置/未定位港口会明确提示并支持**一键补建**
- 交互预览：高德街道 / 高德卫星 / OpenStreetMap 三种底图，港口标记（母港红点、访问港蓝点、Day 角标）、航线走向箭头、海上巡游标注、港口信息弹窗
- **下载 PNG 航线图**：按当前底图合成高分辨率瓦片 + 航线叠加绘制（标题、图例、版权、坐标说明），可直接用于排版/打印
- 航线可保存/加载/删除，内置 9 条示例航线

## 启动

```bash
cd cruise-admin
npm install          # 安装依赖（如 ~/.npm 权限异常，可加 --cache ./node_modules/.npm-cache）
npm run dev          # 开发模式：前端 http://localhost:5173 （/api 代理到 5175）
npm run build        # 构建前端到 dist/
npm start            # 生产模式：http://localhost:5175 （API + 静态页面一体）
```

数据存储在 `data/db.json`（纯 JSON 文件，可直接备份/编辑）。

## 技术栈

- 前端：Vue 3 + Element Plus + Leaflet（高德底图）+ Vite
- 后端：Node.js + Express，JSON 文件存储
- 坐标：港口存储 WGS-84；展示与导出时自动转换 GCJ-02 对齐高德底图（瓦片支持 CORS，可直接合成导出 PNG）
- 陆海判定：`src/assets/landgrid.json` 为 Natural Earth 50m 陆地边界栅格化位图（0.125°），由 `scripts/make-landgrid.mjs` 生成（`node scripts/make-landgrid.mjs <land-50m.topojson>`）
